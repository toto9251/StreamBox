# Accessibility Statement

**StreamBox (ssto-dl)** aims to be usable across terminal environments and operating systems.

## Supported Environments & Features
- **Screen & Terminal Compatibility**: Uses standard terminal text output and `rich` / `questionary` prompts with clear labels and keyboard navigation (`Arrow keys`, `Space`, `Enter`, `Ctrl+A`, `Ctrl+R`).
- **Reduced Visual Effects**: Animations/spinners (`Menu Effects`) are **disabled by default** and can be toggled in **Settings** for users who prefer static output or use screen readers.
- **Cross-Platform**: Works on Windows, macOS, and Linux via Python 3.10+.

## Reporting Barriers
If you encounter accessibility barriers or usability issues in the CLI or interactive menu, please open an [Issue](https://github.com/toto9251/StreamBox/issues) describing your terminal/assistive setup and the problem.
